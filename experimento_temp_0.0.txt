Aqui está um algoritmo de ordenação Bubble Sort em C bem documentado:

```c
#include <stdio.h>

// Função para imprimir um array
void imprimirArray(int arr[], int tamanho) {
    int i;
    for (i = 0; i < tamanho; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

// Função para implementar o Bubble Sort
void bubbleSort(int arr[], int tamanho) {
    int i, j, temp;
    // O loop externo percorre todo o array
    for (i = 0; i < tamanho-1; i++) {
        // O loop interno compara adjacentes e troca se necessário
        for (j = 0; j < tamanho-i-1; j++) {
            if (arr[j] > arr[j+1]) {
                // Troca arr[j] e arr[j+1]
                temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;
            }
        }
    }
}

// Função principal para testar o Bubble Sort
int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int tamanho = sizeof(arr)/sizeof(arr[0]);
    printf("Array original: \n");
    imprimirArray(arr, tamanho);
    bubbleSort(arr, tamanho);
    printf("Array ordenado: \n");
    imprimirArray(arr, tamanho);
    return 0;
}
```

### Explicação do Código:

1. **Função `imprimirArray`**:
   - Esta função recebe um array e seu tamanho como parâmetros e imprime todos os elementos do array.

2. **Função `bubbleSort`**:
   - Esta função implementa o algoritmo de Bubble Sort.
   - O loop externo (`for (i = 0; i < tamanho-1; i++)`) percorre todo o array.
   - O loop interno (`for (j = 0; j < tamanho-i-1; j++)`) compara adjacentes elementos e troca se necessário.
   - Se um elemento é maior que o próximo, eles são trocados usando uma variável temporária (`temp`).

3. **Função `main`**:
   - Define um array de exemplo.
   - Calcula o tamanho do array.
   - Imprime o array original.
   - Chama a função `bubbleSort` para ordenar o array.
   - Imprime o array ordenado.

### Como Funciona o Bubble Sort:
- O Bubble Sort é um algoritmo de ordenação simples que funciona comparando pares adjacentes de elementos e trocando-os se estiverem na ordem errada
